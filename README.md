# Project Transport

All-in-one Logistics SaaS for small to mid-size Dutch transport companies.

**Status:** Planning phase

## Vision
One platform replacing fragmented tools for Dutch logistics companies with 1-50 trucks.

## MVP Modules
1. Order & Route Management
2. Integrated Chat (dispatcher to driver)
3. Proof of Delivery (POD)

## Target
Dutch transport companies — affordable, simple, all-in-one.
