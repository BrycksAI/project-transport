# Project Transport — Plan

## Concept
All-in-one Logistics SaaS for small to mid-size Dutch transport companies.
Web + mobile (both equally important).

## Target Customer
Dutch logistics companies with 1-50 trucks.
Currently using fragmented tools (Excel, phone, WhatsApp, paper).
No central overview. Existing software is too expensive/complex.

## MVP — 3 Core Modules

### 1. Order & Route Management
- Create transport orders
- Route planning with map
- Driver assignment + ETA
- Status tracking: loaded -> driving -> delivered

### 2. Integrated Chat
- Dispatcher <-> Driver in-app chat
- Quick presets ("Laden voltooid", "Onderweg", "Afgeleverd")
- Replaces WhatsApp/phone fragmentation

### 3. Proof of Delivery (POD)
- Driver captures signature + photo on mobile
- Auto-linked to order
- Customer gets delivery confirmation link

## Pricing (exploratory)
- Per-vehicle/month (EUR 49-99/truck/month)
- "Alles inbegrepen" model

## Competition
- Samsara, Motive, Trimble — too expensive for small companies
- Transporeon, Shippeo — enterprise-focused
- Gap: affordable, simple, Dutch-first solution
